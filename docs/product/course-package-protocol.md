# 课程产物协议

## 目标

课程生成流程可以来自本项目内容、外部研究资料、书籍、论文、公开视频或其他教程，但生成成功不等于内容正确或允许发布。

## 必需清单

每个课程版本必须记录：

- 稳定课程 ID、slug 和版本；
- 稳定章节 ID 与顺序；
- 标题、摘要、学习目标和前置知识；
- 输入来源、版本与许可信息；
- 生成器、生成器版本和生成配置；
- 生成时间；
- 技术审核和内容审核状态；
- HTML 产物路径与校验值；
- 代码和内容许可证边界；
- 与 Knowledge、路线、互动和题目的关系；
- 学习进度迁移规则。

## 产物保存

批准后的 HTML 是版本化产物并进入 Git。部署时不重新调用 AI 生成。更新产生新版本，不覆盖无法追溯的旧产物。

## 主站接入

- 主站负责课程入口、元数据、返回导航和学习状态；
- 独立课程通过受限制的嵌入容器接入，防止样式和脚本污染主站；
- 消息协议必须校验来源、消息 Schema、课程 ID、课程版本和章节 ID；
- 课程内部可以使用专用教学布局，但必须满足移动端、键盘和减少动画要求。

## 发布检查

- manifest 与稳定 ID 有效；
- 来源、引用和许可证完整；
- 未批准远程脚本和追踪不存在；
- 链接与资源可用；
- 键盘、移动端和减少动画模式可用；
- 技术内容完成审核；
- 文件大小和性能满足预算；
- 校验值与实际产物一致。

## 学习进度

第一版使用浏览器本地存储，并支持 JSON 导出与导入。状态包含 Schema 版本、课程版本和稳定章节 ID。

语义未改变的章节可以保留完成状态；重大重构、学习目标或验收标准变化时，课程版本必须明确要求重新学习或重新测验。
