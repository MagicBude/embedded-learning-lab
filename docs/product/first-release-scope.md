# 第一版范围与验收

## 产品目标

第一版用一条真实 UART 纵向切片验证：可靠资料能否被整理为可查询资料卡、有出处的主题指南、可循序学习的课程、可操作的互动与实验，以及能够回写来源评价和学习记录的闭环。

页面数量、文章数量和公开流量不是第一版成功标准。

## 页面范围

- 首页；
- 学习路线总览和 UART 路线详情；
- 资料库索引与资料卡详情；
- 主题指南索引与详情；
- 课程索引、UART 课程介绍和学习界面；
- UART 面试题库与题目详情；
- 搜索结果；
- 关于项目；
- 404；
- 来源、内容许可和隐私说明。

## 内容范围

### Sources

首批资料卡覆盖：

- UART 与 STM32F103 的标准、参考手册、数据手册和官方驱动；
- C 缓冲区、对象表示和工具链所需的标准与官方文档；
- 与当前课程直接相关的少量高质量免费教程。

每张资料卡记录版本、许可、阅读定位、适用范围、限制和关联内容。第一版不追求建立通用链接收藏夹。

### 主题指南（内部类型 `knowledge`）

1. 数据表示与字节流；
2. C 语言缓冲区模型；
3. UART 通用原理；
4. STM32F103 USART 实现。

主题指南负责跨来源说明和课程前置，不自称替代标准或厂商手册。允许根据真实篇幅进一步拆页，但不能为了数量制造碎片。

### 课程

一门约 4–6 个单元的 UART 课程，覆盖：

- 硬件体检和安全接线；
- 字节、编码、串行传输和帧；
- 波特率、时钟、采样和误差；
- STM32F103 轮询收发；
- 中断、环形缓冲区、错误状态和排错；
- DMA、消息边界和上层协议的进阶入口；
- 回环实验、测量、自测和面试追问。

### 互动与实验

- UART 信号实验室：调整帧、校验、停止位、波特率和时钟误差，观察传输时间和接收风险；
- STM32F103C8T6 串口命令终端：回显、基本命令、非阻塞接收、环形缓冲、消息边界、错误计数和可复现排错；
- 核心实验只要求开发板、SWD 调试器和 3.3 V USB-UART；逻辑分析仪强烈推荐，示波器用于进阶。

### 练习与题库

- 开课前置诊断，但不锁课；
- 章节即时练习；
- 概念自测、计算题、代码阅读和排错情景；
- 少量 UART 面试题，每题包含 30 秒回答、深入解释、追问、易错点和实验依据。

## 功能范围

- 路线节点状态；
- Sources、主题指南、课程和题库的结构化关联；
- 全文搜索和按内容类型、领域、平台、路线阶段与成熟度筛选；
- 课程进度、自测摘要和上次位置保存在浏览器；
- 学习状态 JSON 导出与导入；
- 浅色与深色主题；
- 响应式布局和键盘操作；
- 来源、许可证和第三方声明；
- GitHub Actions 检查与 GitHub Pages 部署。

## 非目标

- 在线编辑后台；
- 账户与跨设备云同步；
- 完整面试题库；
- 全部知识领域的空栏目；
- 独立 Labs、Projects 和 Tools 一级入口；
- 评论、点赞和社区；
- AI 问答；
- Web Serial；
- RTOS、Linux、BSP 和 IoT 正式课程；
- 商业化系统。

## 验收原则

- 用户能够从路线进入 UART 课程并完成互动、练习和实机实验；
- 来源身份、版本、许可和推荐阅读位置可以独立查询；
- 稳定概念可以通过主题指南回到具体来源；
- 实验结论具有日志、寄存器、波形或其他可复现证据；
- 未达到发布条件的内容不进入正式网站、搜索、站点地图或 RSS；
- 课程进度可以导出、导入并在兼容版本间迁移；
- 公开页面满足约定的可访问性、浏览器和性能要求；
- 一次真实学习反馈能够回写资料评价、主题指南、课程或实验记录，而不篡改外部来源的身份与原意。
