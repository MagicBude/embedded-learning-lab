# 界面线框

本文件记录进入实现前需要确认的页面骨架。线框只确认信息层级、阅读顺序、响应式变化和交互入口，不在这一阶段锁死最终色值或装饰细节。

## 首页

### 桌面结构

┌──────────────────────────────────────────────────────────────────────┐
│ 标志          路线  Knowledge  课程  面试  关于      搜索  主题     │
├──────────────────────────────────────────────────────────────────────┤
│ Embedded Learning Lab                                               │
│ 从原理、实验到工程实践，建立可验证的嵌入式知识体系。                 │
│ [搜索知识、课程或题目……                    ] [从学习路线开始]       │
├──────────────────────────────────────────────────────────────────────┤
│ 当前学习                                                            │
│ UART：从字节、缓冲区到 STM32F103 串口实验      进度 / 下一节入口   │
├──────────────────────────────────────────────────────────────────────┤
│ 学习路线                                                            │
│ 公共主干 → [MCU / RTOS] [Linux 应用] [BSP / 驱动] [网络 / IoT]     │
├──────────────────────────────────────────────────────────────────────┤

### 响应式规则

- 移动端保持与桌面相同的信息优先级，不通过隐藏关键模块来适配；
- 桌面导航在窄屏折叠为菜单，搜索保留独立入口；
- 搜索框和主要行动按钮在移动端纵向排列并占满可用宽度；
- 四条路线分支在桌面可并列，在移动端改为纵向列表；
- 精选内容按课程、Knowledge、面试题的顺序排列；
- “当前学习”只有存在本地进度时展示；首次访问时替换为“建议从这里开始”，不显示空进度。

## 学习路线

### 路线总览

```text
页面标题 + 路线说明 + 状态图例
公共主干：F1 → F2 → F3 → F4
                     ├─ A MCU / RTOS
                     ├─ B Linux 应用
                     ├─ C BSP / 驱动
                     └─ D 网络 / IoT
贯穿能力：测试与调试 ───────── 系统设计与可靠性
```

- 路线节点同时显示名称、状态、阶段目标和预计产出；
- `available` 节点可进入，`in-progress` 显示当前内容范围，`planned` 和 `exploring` 只提供规划说明；
- 桌面端保留分支关系，移动端转换为“公共主干 + 可折叠方向分支”的线性列表；
- 状态同时使用文字和图形，不只依赖颜色。

### 路线详情

```text
面包屑 / 路线名称 / 适合谁 / 完成后能做什么
阶段导航
├─ 阶段目标
├─ 前置知识
├─ 学习内容与可用状态
├─ 阶段产出
└─ 验收清单
相关课程、Knowledge、实验与面试题
```

## Knowledge

### 索引页

- 顶部提供搜索和领域筛选，平台、路线阶段与成熟度作为次级筛选；
- 默认按学习结构和相关性组织，不把发布时间作为唯一顺序；
- 结果条目显示标题、摘要、领域、平台、成熟度和最近验证时间；
- 移动端筛选进入抽屉，当前已启用筛选在结果上方以文字列出。

### 正文页

```text
面包屑
标题 / 摘要 / 领域 / 平台 / 成熟度 / 验证时间
前置知识 + 本文能解决什么
────────────────────────────────────
桌面目录 │ 正文：原理 → 示例 → 边界 → 验证
         │ 代码 / 表格 / 技术图 / 提示与警告
────────────────────────────────────
来源与验证依据 / 已知限制
关联课程、实验、题目与下一篇
```

- 正文是主视觉中心，元数据不得形成压过标题的大型信息面板；
- 通用原理与 STM32F103C8T6 平台实现使用明确标题和平台标识区分；
- 移动端目录变为“本文目录”入口，正文宽度占满安全阅读区域。

## 课程

### 课程介绍页

```text
课程名称 / 简介 / 难度 / 预计学习时间
[开始课程或继续学习]
能学到什么 / 前置要求 / 所需硬件
章节目录与每章产出
实验、练习与验收方式
来源、版本和最后审核信息
```

### 章节学习页

```text
桌面：章节侧栏 │ 章节标题、正文、互动、自测 │ 关联 Knowledge
底部：上一节 / 完成状态 / 下一节
```

- 章节侧栏展示课程进度和当前位置，不承担全站导航；
- 移动端使用章节抽屉，页面顶部始终能看到当前位置和打开目录的入口；
- 独立生成课程在受限容器中接入，并提供加载失败和不支持脚本时的替代说明；
- 自测反馈出现在题目附近，不使用打断阅读的全屏弹窗。

## 面试题

### 列表页

- 搜索与筛选维度为领域、平台、路线阶段和难度；
- 列表默认显示题目、范围、难度和练习状态，不直接铺开完整答案；
- 支持按路线阶段练习，但第一版不引入复杂组卷或排行榜。

### 题目详情

```text
题目 / 领域 / 难度 / 平台
[先自己回答]
30 秒回答
深入解释
常见追问
易错点
工程证据或验证方式
关联 Knowledge / 课程 / 实验
```

- “30 秒回答”默认可见，其余层级按阅读顺序渐进展开；
- 展开状态支持键盘操作，并以标题文本说明内容，不只使用箭头图标；
- 练习结果保存在本地，可导出，不要求账户。

## 搜索

```text
全站搜索框
内容类型 / 领域 / 平台 / 路线阶段 / 成熟度
结果数量与当前筛选
结果列表：类型 + 标题 + 命中片段 + 关键元数据
```

- 桌面筛选位于结果左侧或顶部，取决于可用宽度；移动端统一进入筛选抽屉；
- 无查询时提供可搜索范围和建议入口，不展示伪造热门关键词；
- 无结果时保留原查询和筛选，提供清除筛选与浏览路线两个动作；
- 搜索索引只包含允许发布且应被发现的内容，`unlisted` 不进入索引。

## 通用状态

- **空状态**：说明为何为空，并只提供一个最相关的下一步；
- **错误状态**：说明失败对象、是否可重试和替代入口；
- **加载状态**：只用于真实异步区域，静态内容不制造骨架屏；
- **不可用状态**：路线规划节点明确标记 `planned` 或 `exploring`，不得伪装为可点击内容；
- **离线或脚本失败**：正文仍可阅读，互动区域提供文字说明和恢复建议。
