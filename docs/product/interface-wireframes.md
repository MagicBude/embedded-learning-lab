# 界面线框

本文件记录进入实现前需要确认的页面骨架。线框只确认信息层级、阅读顺序、响应式变化和交互入口，不在这一阶段锁死最终色值或装饰细节。

### 响应式规则

- 移动端保持与桌面相同的信息优先级，不通过隐藏关键模块来适配；
- 桌面导航在窄屏折叠为菜单，搜索保留独立入口；
- 搜索框和主要行动按钮在移动端纵向排列并占满可用宽度；
- 四条路线分支在桌面可并列，在移动端改为纵向列表；
- 精选内容按课程、Knowledge、面试题的顺序排列；
- “当前学习”只有存在本地进度时展示；首次访问时替换为“建议从这里开始”，不显示空进度。
