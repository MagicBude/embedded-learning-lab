# 调研资料

本目录保存项目规划和内容创作过程中产生的调研。

候选分类：

```text
research/
├─ creators/       创作者与内容矩阵
├─ products/       知识库、课程和实验产品
├─ technologies/   框架、搜索、内容和部署技术
└─ references/     官方资料与来源目录
```

只有出现真实调研内容时才创建对应子目录。

调研结论不自动成为项目决策。需要采用的结论必须经过讨论，并写入 `docs/project/decisions.md`。
