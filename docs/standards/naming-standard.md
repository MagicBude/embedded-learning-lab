# 命名规范

## 项目名称

- 正式英文名：`Embedded Learning Lab`
- 中文名：`嵌入式学习实验室`
- 仓库名：`embedded-learning-lab`
- 可用简称：`Embedded Lab`

## 文件和目录

- 普通文件、内容目录和 URL slug 使用 `lowercase-kebab-case`；
- 根目录约定文件和目录导航文件使用行业惯例名称，例如 `README.md`、`AGENTS.md`；
- `docs/` 内其他文档统一使用小写 `lowercase-kebab-case`；
- 缩写仅在它本身是通用行业术语时使用，例如 `i2c`、`uart`、`rtos`；
- 不使用难以理解的拼音或无语义编号作为永久名称。

## 内容标题

- 标题优先表达用户问题或知识对象；
- 不在永久标题中加入“史上最全”“保姆级”“三分钟精通”等营销表达；
- 系列编号属于展示元数据，不应成为文件名的主要语义。
