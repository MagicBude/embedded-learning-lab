# 视觉验收清单

本清单用于页面、组件和内容模板进入主分支前的视觉验收。验收关注实现是否忠实遵守设计系统，并在真实内容和不同设备条件下保持可用，不以单张桌面截图或像素完全相同代替完整检查。

## 一致性

- [ ] 使用 `design-tokens.md` 的语义令牌，不散落未经说明的色值、间距、圆角和阴影；
- [ ] 同类页面遵循 `interface-wireframes.md` 的信息顺序；
- [ ] 同一组件在不同页面保持相同结构、状态名称和交互方式；
- [ ] 没有直接采用 Astro 示例主题或第三方组件默认外观；
- [ ] 新视觉模式已先更新设计文档。

## 排版与内容

- [ ] 正文阅读宽度、字号和行高适合连续阅读；
- [ ] 标题层级连续且每页只有一个主标题；
- [ ] 中英文、数字、术语和代码混排没有明显断行或间距问题；
- [ ] 长标题、URL、寄存器名和代码不会覆盖相邻内容；
- [ ] 不使用虚构统计、占位卡片或无意义文案填充空内容。

## 色彩与主题

- [ ] 浅色和深色主题下文字、边框、焦点和状态均清晰；
- [ ] 主题切换不会引起布局跳动或内容丢失；
- [ ] 颜色对比度达到 WCAG 2.2 AA 目标；
- [ ] 成功、警告、错误、成熟度和路线状态不只依赖颜色；
- [ ] 技术图、代码高亮和数据标记在两种主题下均可辨认。

## 响应式与交互

- [ ] `320px` 宽度下不存在页面级横向滚动；
- [ ] 手机、平板和桌面至少各检查一个代表宽度；
- [ ] 导航、筛选、目录和课程侧栏按线框规则折叠，不直接消失；
- [ ] 表格、代码和大型技术图只在自身区域发生必要滚动；
- [ ] 键盘可到达所有交互，焦点清晰且顺序与阅读顺序一致；
- [ ] 默认、悬停、焦点、激活、选中、禁用、错误和加载状态按实际能力实现；
- [ ] 减少动画模式不会丢失状态或空间关系。

## 内容类型

- [ ] Knowledge 呈现来源、验证依据、平台范围和已知限制；
- [ ] 课程显示章节位置、进度、前后导航和关联 Knowledge；
- [ ] 面试题按短答、深解、追问、易错点和工程证据渐进呈现；
- [ ] 路线节点区分可学习、建设中、已规划和探索中；
- [ ] 搜索结果显示内容类型、命中片段和关键元数据。

## 降级与真实性

- [ ] JavaScript 失败时正文和主要导航仍可使用；
- [ ] 互动区域有加载失败、不支持或离线时的说明；
- [ ] `planned` 与 `exploring` 不伪装成已经存在的内容；
- [ ] 首次访问没有本地进度时显示“建议从这里开始”；
- [ ] 只展示真实可用的数量、日期、验证状态和最近更新。

## 验收记录

每次页面级验收至少记录页面或组件、对应提交、检查的视口与主题、自动化结果、人工发现、处理结论和已接受限制。
