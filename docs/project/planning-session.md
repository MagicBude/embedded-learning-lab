## UART 第一条纵向切片

- **Q31 硬件基线 — 确认：** 可核验的 STM32F103C8T6 最小系统板，按 64 KB Flash；SWD 调试器与 3.3 V USB-UART 分工；不依赖板载 USB；兼容芯片另作变体说明。
- **Q32 STM32 开发方式 — 选择 B：** STM32Cube HAL 为主，解释关键寄存器、时钟、状态位和中断路径，必要处加入裸寄存器小实验。
- **Q33 C 语言前置 — 选择 B：** 设置最小前置知识和诊断，缺失时进入真实存在的 Knowledge，UART 课程不从变量开始重讲全部 C。
- **Q34 仪器要求 — 选择 B：** 核心只要求开发板、SWD 和 3.3 V USB-UART；逻辑分析仪强烈推荐，示波器进阶；模拟与预采集波形不能冒充实测。
- **Q35 UART 课程骨架 — 接受：** 硬件体检；字节与帧；波特率与采样；轮询；中断、缓冲和错误；DMA 与消息边界；回环、测量、自测和追问，最终整理为约 4–6 个课程单元。
- **Q36 建设顺序 — 确认：** 采用路线指导的纵向切片，先完成 UART 最小前置知识，不先填满整条路线，也不允许无效前置链接。
- **Q37 最小 Knowledge — 接受：** 数据表示与字节流；C 缓冲区模型；UART 通用原理；STM32F103 USART 实现。
- **Q38 第一版互动 — 选择 C：** 组合式 UART 信号实验室，可调整帧、校验、停止位、波特率和时钟误差并观察结果。
- **Q39 实机项目 — 选择 B：** 小型串口命令终端，包含回显、基本命令、非阻塞接收、环形缓冲、消息边界、错误计数和可复现排错。
- **Q40 诊断与考核 — 选择 B：** 开课诊断、章节练习、概念自测、计算题、代码阅读、排错情景和实机验收；不强制锁课。

## Git 工作纪律、CI 与测试

- **Q62 编辑冲突 — 选择 B：** 以基础版本检测仓库变化，冲突时禁止自动覆盖并展示差异，发布仍需预览和检查。
- **Q63 课程进度迁移 — 选择 B：** 进度绑定稳定课程 ID 和章节 ID；语义未变的章节保留状态，重大变化显式要求重学或重测。

## 内容元数据与来源模型

- **Q53 成熟度与发布状态 — 选择 B：** 成熟度使用 `capture / draft / review / verified / archived`，可见性使用 `private / unlisted / public`，发布时间单独记录为 `publishedAt`；这项决定修正 Q8 中把 `published` 放入成熟度的旧表述，但保留两个维度独立的原则。
- **Q54 公共元数据 — 接受：** 所有内容使用稳定 `id`，并按适用性记录 `title`、`slug`、`summary`、`type`、`domain`、`tags`、`platforms`、成熟度、可见性、时间、前置、关联、来源、作者和许可证；可选字段允许省略，不填写虚假占位值。
- **Q55 来源精度 — 选择 B：** 结构化记录来源类型、标题、作者或机构、URL、文档编号、版本、章节或页码、访问日期、许可证和所支持结论；正文通过来源 ID 引用。
- **Q56 通用与平台实现 — 选择 B：** 通用 Knowledge 是权威基础；平台实现较短时放在明确分区，增长后拆成关联实现页，不复制通用正文。
- **Q57 内容格式 — 选择 B：** 默认使用标准 Markdown 与结构化 YAML；只有真正需要互动组件的课程章节或实验使用 MDX。
