UART 入门速查

这不是课程替代品。用于学过之后快速回忆术语、公式和排查顺序。

一句话

UART 是把内部数据转换为按时间排列的串行 bit，并从串行电平恢复数据的异步收发外设。

最小双向连接

A.TX → B.RX
A.RX ← B.TX
A.GND ─ B.GND

8N1

起始位1 bit，通常为低
数据位8 bit，常见最低有效位先发
校验位N：无校验
停止位1 bit，通常为高
总计10 bit/单字节帧

公式

位时间 = 1 ÷ 波特率
帧位数 = 起始位 + 数据位 + 校验位 + 停止位
帧时间 = 帧位数 ÷ 波特率
理论有效字节率 = 波特率 ÷ 每帧位数

容易混淆

  • UART 不是 USB，也不是 USB-UART 模块。
  • UART 帧规则不是 RS-232 或 RS-485 电气标准。
  • 能收发字节不代表已经有消息边界、校验和重传。
  • 串口终端是软件，不是 UART 外设。

无输出或乱码时

  1. 确认共同 GND 和电平兼容。
  2. 确认 TX→RX、RX←TX。
  3. 确认双方波特率、数据位、校验和停止位一致。
  4. 先发送固定重复字节。
  5. 查看错误标志，有条件时测量位宽和波形。
