Lesson 01 · 从零开始

UART 是什么：从设备到线路

本课目标：能说明 UART 解决什么问题、怎样连接、规定与不规定什么，并把字符 A 逐步转换成线路上的 8N1 帧。

1. 先从一个真实问题开始

STM32 读到了温度值 25，怎样把它交给电脑显示？可以准备很多根线，同时送出所有 bit；也可以只用一根发送线，让 bit 按时间一个接一个通过。后者减少了引脚和导线，这就是串行传输的基本想法。

UART（Universal Asynchronous Receiver/Transmitter，通用异步收发器）是 MCU 或其他芯片中的通信外设。它把内部数据转换成按时间排列的串行 bit，也能从串行电平中恢复数据。

  • Universal：不绑定某一种传感器或消息格式。
  • Asynchronous：两端不额外连接持续工作的共享时钟线。
  • Receiver/Transmitter：同时包含接收和发送方向。
异步不等于不需要时间约定。没有共享时钟线后，两端更需要事先约定波特率、数据位、校验和停止位。

2. UART 在完整系统里处于哪一层

STM32 程序
  │ 交给 USART1 一个或多个字节
  ▼
STM32 USART1 ── TX/RX 高低电平 ── USB-UART 转换器
                                      │ 转成 USB 数据
                                      ▼
                                  电脑串口驱动
                                      │
                                      ▼
                                  串口终端软件

STM32F103 上常见的是 USART（通用同步/异步收发器）。它比纯 UART 多了同步能力；配置成异步模式后，就是本课讨论的 UART 用法。USB-UART 是两种接口之间的转换器；串口助手则只是查看和发送电脑串口驱动交付字节的软件。

3. 最小连接为什么通常有三根线

设备 A                         设备 B
TX（发送） ─────────────────▶ RX（接收）
RX（接收） ◀───────────────── TX（发送）
GND       ─────────────────── GND

一个出口应连接另一个入口，所以 TX 接对方 RX。GND 建立共同电压参考；没有共同参考，两端可能无法一致判断高低电平。独立的 TX 与 RX 允许两个方向同时工作，因此称为全双工。

接线前：本课程使用 3.3 V UART 电平。不要把传统 RS-232 电平或 USB 的 D+/D− 直接接到 STM32 GPIO，也不要在不了解供电关系时连接 USB-UART 的 VCC。

4. UART 规定什么，又不规定什么

UART 处理一帧 bit 的时间结构；它不自动规定插头、长距离线路电气标准、消息含义、消息结束位置和重传机制。

5. 字符怎样走到 TX 引脚

  1. 人看到字符 A。
  2. ASCII 把它映射为数值 65，也就是 0x41。
  3. 程序把这个字节交给 UART。
  4. UART 按帧格式加入边界信息。
  5. TX 在每个位时间输出高低电平。
  6. 接收端采样并恢复 0x41。
  7. 应用再次按 ASCII 解释时才显示为 A。

UART 不知道 0x41 是字母、传感器数值还是命令的一部分；含义由应用层决定。

6. 空闲、起始位和 8N1

常见异步 UART 空闲时保持高电平。起始位把线路拉低，接收端据此开始计时；随后发送数据位，最后以高电平停止位结束。8N1 表示 8 个数据位、无校验、1 个停止位，加上起始位共 10 个位时间。

普通写法：D7 D6 D5 D4 D3 D2 D1 D0 = 0 1 0 0 0 0 0 1
时间顺序：Start D0 D1 D2 D3 D4 D5 D6 D7 Stop
            0    1  0  0  0  0  0  1  0   1
